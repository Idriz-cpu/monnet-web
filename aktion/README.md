# Aktions-Landingpage Wärmepumpe (WP10)

Eigenständige, statische Seite für den Instagram-Bio-Link. Unabhängig von der Astro-Webseite.

- `index.html`: Formular, Texte in DE/FR/EN (Sprache über `/`, `/fr`, `/en`)
- `danke.html`: Danke-Seite (nur ohne JavaScript)
- `datenschutz.html`: Datenschutzhinweise (bitte prüfen lassen)
- Formularversand: Netlify Forms (Formularname `wp-anfrage`), Benachrichtigung an info@mon-net.eu im Netlify-Dashboard einstellen
- Instagram-Link mit Quelle: `https://<domain>/?utm_source=instagram&utm_campaign=wp10`
